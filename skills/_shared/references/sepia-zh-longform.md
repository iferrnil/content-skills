# 长文节奏检查（sepia 裁剪）

来源：[sepia](https://github.com/Nanako0129/sepia) 的结构/节奏与中文校准思路（含 `references/languages/zh.md`）。本页只抽**大陆简中自媒体长文**能用的检查项；**不**套用 sepia 的繁中新闻标点与台湾用词规范。

配合 [`unslop-zh.md`](./unslop-zh.md) **B. 长文档**：先完成短帖档套话清洗，再过本清单。只改表达，不增事实。

## 检查清单

1. **句长有起伏**  
   通读时标出连续三句以上「差不多长」的齐整短句；拆并或拉长短句，避免机读感连排。不必追求固定均长。

2. **连词少叠**  
   跨句堆「和 / 以及 / 并且 / 同时 / 此外 / 因此 / 然而」时删减；中文可用并置、短句承接，不必句句粘连。

3. **双音节注水 → 单动词**  
   「进行讨论 / 加以说明 / 做出调整」等 → 讨论、说明、调整。

4. **小标题与封面**  
   小标题别口号化（「破局之道：双轮驱动」类）；封面/主标题禁空壳标题党（一文读懂、重磅、保姆级等已在短帖档）。

5. **语气词克制**  
   口语长文可偶发点缀；正式公众号勿硬塞「嘛 / 喔 / 啦」。

6. **「不是…而是…」**  
   单次、有信息量可留；成串空洞对比才砍（与短帖档「假不是而是」一致，长文容忍度略宽）。

7. **事实门禁**  
   改写后核对：未新增原文没有的数字、因果、引语；吃不准标 `[待核实]`。流程可借鉴 ZeroSlop 的「改写后再过事实门」思路，不用其英文词表。

## 明确不做

- 不安装/不依赖完整 sepia skill；规则已写入本仓库。
- 不把台湾标点、繁体用词、新闻体例默认套到大陆简中推特长文/公众号。
- 不为「像 sepia」而统一拉长句子或统一改成某一种书面腔。
