# IP 资产（长文正文配图）

供 [`ai-longform-illustrations`](../../ai-longform-illustrations/) 使用：固定角色参考图 + 身份锚点文案。

## 文件

| 文件 | 说明 |
| --- | --- |
| `ip-reference.jpg` 或 `ip-reference.png` | **唯一**角色参考图（必填才能正式生图） |
| `ip-character.md` | 身份锚点 / 可变项 / 禁止项 / 画风默认 |
| `ip-reference.PLACEHOLDER.md` | 尚无正式图时的占位说明；有正式 jpg/png 后可删 |

## 如何替换参考图

1. 准备一张清晰、正面或 3/4 侧面、角色特征明显的图（建议白底或干净背景；不要复杂自拍场景当「姿势模板」）。
2. 放到本目录，命名为 **`ip-reference.jpg`** 或 **`ip-reference.png`**（二选一即可；skill 检测到其一即可开跑）。
3. 删除或忽略 `ip-reference.PLACEHOLDER.md`（可选清理）。
4. 参考图只用于**锁定长相与气质**；生图时不要复刻其中的房间、自拍角度或姿势。

## 如何改身份锚点

1. 编辑 `ip-character.md`：改「身份锚点（不可变）」「可变项」「禁止项」「画风默认」。
2. 与参考图保持一致：文案写「圆框眼镜」则参考图也应是圆框，避免文图打架。
3. 默认文案是**占位**（温和、AI 自媒体向卡通化「戴眼镜的创作者」）；请换成你自己的正式设定后再用于对外内容。

## 无参考图时

- skill **默认停止生图**，请你补图。
- 仅当你明确说「先用纯文字描述试跑」时，才可按 `ip-character.md` 试跑，并警告一致性差。
