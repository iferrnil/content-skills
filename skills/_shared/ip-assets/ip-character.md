# 个人 IP 身份锚点（占位 · 请换成你的正式设定）

> **占位说明**：以下是温和、AI 自媒体向的卡通化「戴眼镜的创作者」默认描述，仅供试跑与结构对齐。对外发布前，请用户替换为本目录正式参考图 + 自己的设定。

## 角色定义

正文配图中的固定叙事主角，不是角落贴纸。应承担画面中最关键的解释动作：连接、搬运、分类、修补、选择、推动、观察、搭桥等。

气质默认：温和、认真、略带好奇；像亲自把观点讲清楚的创作者，不夸张卖萌。

## 身份锚点（不可变 · 每张必须保留）

- 东亚向、偏年轻创作者感的柔和脸型与浅/自然肤色
- 简洁短发（或用户正式设定中的固定发型）；发色与参考图一致
- **眼镜**为重要识别符号（默认细边圆框或方圆适中框；以参考图为准），不能省略或换成墨镜（除非正式设定如此）
- 温和眼神、克制表情；不卡通表情包化
- 默认穿搭：简洁衬衫或休闲创作者上衣（色调以参考图为准）
- 手绘 / 轻线稿呈现角色；少量平涂上色即可，不做写实 3D 材质

## 可变项

- 姿势、手势、视线、道具、远近景随锚点改变
- 可为叙事加极小功能性配件（便签、手套、小工具），但不改发型/眼镜/总体穿搭气质
- 表情可在专注、思考、轻微疑惑、如释重负之间变化；避免夸张大笑、哭喊、嘟嘴

## 禁止项

- 不变成其他性别、年龄段、真实名人、动物、机器人或无关吉祥物
- 不擅自改发色、眼镜轮廓、脸部比例与默认穿搭总体感觉
- 不用 3D 渲染、软陶/玩偶广告光、照片写实皮肤
- 不复制参考图的房间、自拍俯拍、固定半身站姿当「唯一姿势」
- 不加水印、未授权品牌 Logo、无法辨认的胸针长字

## 画风默认（可被任务临时覆盖）

- 画幅：**16:9**
- 背景：白底或浅底，留白充足
- 线条：手绘 / 轻线稿；角色少量上色
- 标注：每张 **2–5** 处短中文；红/橙强调要点，蓝作次要说明（克制使用）
- 信息量：每张只讲一个认知锚点；角色与主物件合计约占画面 40%–60%
- 禁忌观感：PPT 信息图、商业海报、密集 UI、课程封面大标题刷屏
