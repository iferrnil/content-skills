# 配图 QA 清单

每张生成后过一遍；不合格优先**重生成该张**，不要硬修成另一个人。同图最多针对性重试 2 次；每次只修一个主问题。

## 必查

1. **身份一致**：一眼是否同一 IP（发型、五官、服装、气质与 clean reference + `character-spec.md` 一致）
2. **主角在做事**：是否在做解释观点的动作（不是角落卖萌贴纸）
3. **不像 PPT / 海报 / 商业 KV**：无巨型标题、无密信息图、无完整室内外大场景刷屏
4. **画风纯净**：与角色包锁定的 `style` / 参考图一致，未混入无关视觉语言或第三方预设
5. **模式达标**：
   - 流程拆解：3–5 节点，阅读顺序清楚，留白够
   - 核心动作：一人、一动作、一可见结果
6. **中文文字**：短标注无错字；错字多则减少文字后重试
7. **参考图用途正确**：未把设定板的边框、标题、多视图排版、原照片背景拷进正文插图
8. **画幅与留白**：16:9；主体约 55%–70% 画幅高度；四周连续留白；纯白或浅底延伸到四边
9. **景别全身（默认）**：头到脚含鞋可见；未要求特写却裁到腰/大腿 → 不合格重生成
10. **硬锚点**：眼镜、发型、固定服装等 character-spec 写明的不可丢项必须在

## 禁止声称

- 无输出文件却写「已生成」
- 无 `confirmed` 角色或无 clean reference 文件却继续批量配图
- 用 draft 角色出文章插图

## 局部修复（可选）

- 错字标注：只删指定文字，白底补齐，角色与构图不动
- 角色不像：只修身份锚点，场景与标注不动
