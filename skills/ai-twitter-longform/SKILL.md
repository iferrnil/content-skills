# 根据链接或 brief 写推特长文（含封面）

产出可发到 X 的**长文/文章体**（不是单帖短推），并配套**封面图**方案。主题偏 AI/科技。

## 与 ai-twitter-post 的区别

| | `ai-twitter-post` | 本 skill |
| --- | --- | --- |
| 形态 | 默认一条短帖；必要时短线程 | 长文/文章结构 |
| 封面 | 不需要 | **必须**：交付封面图或可生成的封面说明 |

用户说「发条推」「一条发完」→ 用 post skill。说「推特长文」「X Article」「要封面」→ 用本 skill。

## 默认

- 中文；可按要求出英文
- 口语、去 AI 腔；忠于原文，禁止臆造
- 文末带来源链接（有原文时）
- **封面必交付**（见下）

## 输入（双入口）

- **模式 A · 有链接**：用户给 URL（可加一句角度）
- **模式 B · 无链接**：用户给主题/素材/一句话 brief

缺链接且 brief 太空 → 只问一句：「给谁看、想强调什么」。有链接或 brief 够用 → 直接开干。不连环追问。

## 步骤

### 模式 A（有链接）

1. 按 [`../_shared/references/fetch-jina.md`](../_shared/references/fetch-jina.md) 用 **Jina** 拉 Markdown（本阶段只用 Jina）
2. 定角度（谁在乎、和同类差在哪）
3. 按本平台形态写长文（见下）+ **封面必交付**
4. 套 [`../_shared/references/voice-profile.md`](../_shared/references/voice-profile.md) + 去 AI 味（长文 A+B）
5. 交付

### 模式 B（无链接）

1. 根据输入出 **3–5 个选题**（标题 | 角度一句 | 为何现在发）
2. 用户未指定时默认选**最稳**的一个，并在交付里标明选了哪个、备选是什么；用户当场点名则用指定
3. 无原文时严禁编造具体新闻事实/数字；清晰标注「基于 brief 的创作，非转载」
4. 同后写 + 封面 + IP + unslop（长文 A+B）

### 写长文正文

建议结构：

1. 标题（可检索、含实体或反差）+ 2 个备选
2. 开头迅速交代发生了什么、为何值得读
3. 2–4 个小节（事实 → 含义 → 对谁有用）
4. 收束：一句可带走的判断
5. 来源链接（有则带）

长度按内容定，不要灌水；也不要压成单帖。

写完结构后做一遍**长文档**节奏检查（句长起伏、连词堆砌、小标题口号化；见 unslop-zh.md 长文档与 sepia-zh-longform.md）。

### 封面图（必做）

每次交付必须包含封面，任选能完成的路径：

1. **生成图**：按平台横版比例出图（优先贴近 X 长文/文章头图习惯；若工具只支持方图，说明并给出裁切建议）
2. 若当前环境不能出图：给出**可直接用来生成的封面 brief**（主标题文案、副文案、视觉元素、色调、构图、勿出现的元素），并标明「待生成」

封面 brief / 出图要求要点：

- 主标题短、可读；避免大段正文刷屏
- 与文章主题一致，不堆无关科技光效
- 留安全边距，文字别贴边
- 不要伪造未授权的品牌 Logo；可用文字点名产品

正文定稿后若用户要配图 → 调用/遵循 [`ai-longform-illustrations`](../ai-longform-illustrations/)；**封面图仍由上方封面步骤负责，正文配图与封面分开**。

## 交付

1. 标题 + 备选标题
2. 长文正文（可复制）
3. **封面图附件，或完整封面 brief**
4. 依据来源一行（模式 A）；模式 B 标明「基于 brief，非转载」+ 所选选题与备选
5. 有推断单独标明
6. （可选）需要正文配图时，接着跑 [`ai-longform-illustrations`](../ai-longform-illustrations/)（或用户说配图时自动续跑）

## 不做

- 不默认写成单帖短推（应改走 `ai-twitter-post`）
- 不写成公众号/小红书体例
- 不整页搬运原文
- 不臆造原文事实；Jina 失败则说明卡点，请用户粘贴正文或换链

## 去 AI 味

交稿前先按 [`../_shared/references/unslop-zh.md`](../_shared/references/unslop-zh.md) **短帖档**洗套话，再按 **长文档**（及 [`sepia-zh-longform.md`](../_shared/references/sepia-zh-longform.md)）检查句长起伏、连词堆砌、小标题口号化。只改表达，不增事实。  
交稿前对照 [`../_shared/references/voice-profile.md`](../_shared/references/voice-profile.md) 调语气；不与 IP 冲突的去腔优先。
