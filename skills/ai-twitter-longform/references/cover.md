# X Articles 封面（本 skill）

## 尺寸

- 平台约定比例：**5:2**（社区观察值；官方未长期挂像素表）。
- **交付目标**：`1600×640` px（5:2）。也可用 `1500×600` / `1000×400`，须保持 5:2。
- 出图工具若只有 `16:9` / `1:1` 等：先出横版（优先 16:9），**居中裁切到 5:2** 后再交付；备注写「已裁至 5:2」。

## 贴合正文（硬）

1. 等标题与主线定稿后再画；封面主文案 = 本篇标题的压缩版，或主线里那一个实体词。
2. 画面锚点必须来自正文：具体产品名、场景（如企业 Agent / 开发者节 / Token 接到业务），禁止与本篇无关的通用 AI 光效、随机机器人。
3. 读者只看封面，应能猜到这篇在讲哪一类事；猜成另一篇发布会通稿 → 重做。
4. 不默认画个人 IP 角色（正文配图才走 `ai-longform-illustrations`），除非用户点名。

## 文案与安全

- 主标题 ≤ 约 12～16 个汉字为宜；副文案一行可选。
- 留边距，字不贴边、不压关键视觉锚点。
- **禁止**伪造未授权 Logo / 商标图形；可用纯文字写产品名。
- 禁空壳：「一文读懂」「重磅」「保姆级」。

## 交付

- 优先：已裁 5:2 的图片附件 + 一行说明（主文案、是否裁切）。
- 不能出图：完整 brief（主副文案、视觉锚点、色调、构图、勿出现元素、目标 1600×640 / 5:2）并标「待生成」。
