# 叙事与事实（推特长文）

吸收自 `wechat-author-ai`。分栏是幕后清单，不是正文大纲。

## 校准三条

1. 中间带  2. 3～5 要点（例子通常 1～2 个写透）  3. 留平淡

## 事实分栏

| 栏 | 进正文？ | 写法 |
| --- | --- | --- |
| 已核对 | 是 | 能指回来源的数字/产品/门槛 |
| 对方说法 | 是，标清 | 首次/实测 → 他们说 |
| 对照 | 慎用 | 两边都有出处 |
| 判断 | ≤1 句 | 有代价 |
| 无法确认 | 否 | 删 |

## 结构坏味道 → 整篇重写

缩写稿；年表>3；点名>3；替作者反省；议论文腔（两股力/短线长线/新稳态）；连续≥3 句无人话；无人可带走的预期。

## 怎么讲

- 先有「读者带走」，再挂例子。
- 开场一件具体事；禁文里/文中/原稿对照痕迹。
- 事实后立刻人话；「在我看来」≤1。
- 删除测试 + 对调测试。
